# AI use disclosure

MediSpace used ChatGPT and OpenAI Codex during development to propose, generate, and review parts of the Python backend, HTML templates, CSS, JavaScript, and documentation. This disclosure describes the assistance used across the project. Tool use was not tracked line by line. The [provenance inventory](ai-provenance.json) provides the metadata in JSON format.

| Material | Where AI was used | How it is identified |
|---|---|---|
| Facial images | The image sheets `static/emociones/rostros-a.png` and `rostros-b.png` supply the stimuli for the Facial Emotion Recognition task (ERT). The specific image generator was not recorded. | Each face displays a visible “AI-generated image” label in a strip below the stimulus during the test. The original sheets are retained as inputs. |
| Logos | The team supplied the emblem and wordmark in `static/marca/`, which were created with ChatGPT. | The label “AI-generated images · ChatGPT” appears below the two images in the page header and on the sign-in screen. The source JPEGs are retained as inputs. |
| Audio | When enabled, ElevenLabs voices responses in medical monitoring, support chat, and emergency chat. The browser's speech synthesis can also read responses aloud without creating a downloadable MP3 in MediSpace. | The voice controls identify synthesized speech. ElevenLabs audio carries an ID3v1.1 tag titled “AI-generated audio” with the comment “AI-generated by ElevenLabs.” [ID3 metadata format](https://id3.org/ID3v1) |
| Data generated at runtime | Google Gemini writes medical monitoring questions and assessments, psychological follow-up guidance, and support and emergency chat responses. | Newly saved outputs include the `procedencia` field with the provider and model. Chat messages are labeled as AI. |

## Cognitive tests

ChatGPT and OpenAI Codex assisted with the implementation of Motor Praxis (MP), Visual Object Learning Test (VOLT), Line Orientation Test (LOT), Fractal 2-Back (F2B), and Facial Emotion Recognition (ERT). This included code for presenting stimuli, recording responses, and measuring response times. ERT also uses AI-generated faces with a visible disclosure.

MediSpace calculates questionnaire scores and cognitive test results using the rules implemented for each assessment. Gemini does not score cognitive test responses. Measurements and responses entered by people retain their original provenance.
